# Declaració d’accessibilitat

Creative Rent es compromet que aquest lloc web sigui accessible, amb l’objectiu de complir el nivell AA de les Pautes d’Accessibilitat per al Contingut Web (WCAG) 2.1.

## Mesures adoptades
- Contrast de color suficient entre text i fons.
- Navegació completa amb teclat i focus visible.
- Textos alternatius a les imatges.
- Disseny adaptable a qualsevol mida de pantalla, amb zoom permès.
- Les animacions s’aturen si el dispositiu té activada l’opció de reduir el moviment.
