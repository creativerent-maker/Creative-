# Declaración de accesibilidad

Creative Rent se compromete a que este sitio web sea accesible, con el objetivo de cumplir el nivel AA de las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1.

## Medidas adoptadas
- Contraste de color suficiente entre texto y fondo.
- Navegación completa con teclado y foco visible.
- Textos alternativos en las imágenes.
- Diseño adaptable a cualquier tamaño de pantalla, con zoom permitido.
- Las animaciones se detienen si el dispositivo tiene activada la opción de reducir el movimiento.
